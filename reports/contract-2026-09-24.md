# Track 3 evaluator contract audit

Checked 2026-09-24 against primary NVIDIA project and dataset sources. Assignment 01. This is a project readiness report, not official challenge rules. Machine-readable decisions are in `configs/evaluator/contract.json`; API observations are in `configs/evaluator/source-checks.json`.

**The Track 3 policy interface and submission schema remain unresolved.** The official website and dataset card instruct participants to use `eval_e2e.py`, but it was absent from every complete source tree checked: release/0.2.0, release/0.3.0, current main, and the rules-draft branch. No official Track 3 evaluator was run, and no compliant policy architecture can yet be fixed. This establishes absence in the inspected trees, not that no evaluator exists elsewhere.

## Published facts

Track 3 evaluates conversion from egocentric demonstrations to executable robot behavior. Explicit reconstruction/retargeting, implicit pretrained models, and hybrids are allowed approaches. Submission includes reconstructions and recorded policy evaluations packaged by the named evaluator. Award eligibility requires a valid final submission, agreed research-license code release, and a short technical report. The published freeze is November 4, 2026, 17:00 EST (22:00 UTC; November 5, 09:00 AEDT). The site states five submissions weekly and unlimited submissions in the final three days; exact quota-reset semantics remain unspecified. [Official challenge page](https://nvidia-isaac.github.io/video_to_data/v2d_challenge/), [dataset submission guidance](https://huggingface.co/datasets/nvidia/video_to_data_challenge/blob/5f68335f3acc802033d1e80728c1633197521de8/README.md)

The released public data describes 20 episodes, ten tasks, three ego camera streams, object trajectories, meshes, URDFs, and calibration. Camera A is RGB; B/C form a mono stereo pair. Public object poses are metric `world_T_object`, with scalar-first quaternions, episode-specific horizontal origins, and invalid zero poses when invisible. Camera-to-mocap-world extrinsics are absent. These are **input conventions**, not an evaluator output schema or permission to expose reference poses to a rollout policy. [Pinned Track 3 README](https://huggingface.co/datasets/nvidia/video_to_data_challenge/blob/5f68335f3acc802033d1e80728c1633197521de8/track_3/README.md)

The live leaderboard JSON and the pinned website source publish these Track 3 display fields. They establish labels, directions and links, not formulas, thresholds or aggregation. ## Proposals kept separate

The [unmerged rules draft](https://github.com/nvidia-isaac/video_to_data/blob/3889b7cf4558529d0d76690b0cec36835d2915fa/docs/v2d_challenge/rules.html) explicitly awaits organizer confirmation. Its public/private ranking split, late-materials policy and registration acknowledgment are proposals, not current requirements. It also predates the now-published freeze time, so its unresolved deadline wording must not override the current website.

Local proposal: continue public-data decoding, calibration and reconstruction diagnostics with explicit provenance. Keep public-reference diagnostics separated from video-only evaluation inference. Defer architecture decisions that depend on U02–U07, and label any generic simulator experiment as an engineering smoke test. Do not call locally invented packages official submissions. These are project safeguards, not challenge rules.

Recheck official source revisions and the linked competitions before selecting a policy interface and before packaging. Resolve U01–U11 through published evaluator code/rules or documented organizer clarification. The config intentionally uses `null` for unresolved values and `ready_for_official_evaluation: false`; callers must check status rather than silently supplying generic defaults.

Validation: parsed both JSON artifacts, checked unique requirement IDs, verified evidence references and null unresolved values, and verified complete source-tree checks contain no evaluator match. No dependencies, JavaScript, weights, simulation or GPU jobs were added or run.
