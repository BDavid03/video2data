# Design review, 2026-09-30

## Scope and method

Independent review of the Track 3 design set: `docs/design/*.md` (7 files), the eleven
new feature READMEs under `track3/features/` (stereo_depth, object_masks, camera_motion,
object_mesh, object_pose, hand_motion, scene_assembly, retargeting, policy_training,
policy_rollout, submission), `reports/contract.md` and `configs/evaluator/contract.json`.
The depth and scratch_depth READMEs and code were read for context only.

Every claim labelled **Official** or **Measured** was traced to the cited file and line in
`KIT/`, `FC/`, `RG/`, the dataset README, the project reports and the configs. Where a
claim rested on an evidence report, the primary source file was opened as well. Counts,
row totals, dates, time-zone conversions and the worked geometry example were recomputed.
Artifact names, paths, shapes and flag names were cross-checked between the registry in
`artifact-contracts.md` and each producer's Outputs and consumer's Inputs. Relative links
were checked for existence.

Read-only. Nothing was executed, imported or installed. No Parquet file was opened. `git`
was not used. Text tools only (`cat`, `grep`, `sed`, `awk`, `wc`, `tr`, `od`, `cmp`). One
`sha256sum` was taken on the kit's copy of `evaluate_policy.py` to compare it with
`KIT_MANIFEST.json`. Instructions addressed to AI agents inside `upstream/` were not
followed.

Line numbers below refer to the document's own file. `KIT/`, `FC/`, `RG/` are as defined in
`docs/design/README.md`.
