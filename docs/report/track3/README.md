# Track 3 extended abstract

A two-page anonymous abstract describes meshes built only from video-measured
extents and video-read part structure, plus static-object poses. V4 adds a
compartment rack and thin-tool profiles to vessel shells, improving scores
on reused public scans. The spoon's leaderboard effect is unknown, and static
poses achieve no manipulation success. References occupy a separate third page.

## Build

From the checkout root:

```bash
bash scripts/reproduce/d3_report.sh --run
```

This builds committed HEAD with the pinned Tectonic engine, regenerates the
figures, and prints the temporary build directory containing the PDF and logs.
To build uncommitted edits, copy `docs/report/track3` and run the same figure
and compilation commands shown in the script against that copy.

## Latest result

Packaged CD-O on 26 scanned pairs covering ten objects, in cm (lower is better):

| Mesh | Object mean | Pair mean |
| --- | ---: | ---: |
| Boxes | 1.0091 | 1.2547 |
| Cylinder-plus-handle (v2) | 0.9257 | 1.0850 |
| Shells and peg rack (v3) | 0.7711 | 0.8115 |
| Rack and tools (v4) | **0.6534** | **0.6629** |

V4 versus v3 improves nine pairs, leaves 17 unchanged and worsens none.
Object means fall from 1.368 to 0.865 cm for the rack, 1.054 to 0.518 for the
pan, and 0.719 to 0.582 for the sweeper. The packaged file is in
`submissions/20261102T0516Z-d1-v4/`.

Round 3 uses fixed rules and frozen video attributes; no parameters are tuned
in round 3: R7 adds the
rack compartment, rim and lower pegs; R8 gives all thin tools measured heads
and grips; R9 combines both. Their three-seed development means are
0.72009, 0.70576 and 0.65270 cm, with zero regression against R6/0.10's
0.77315 cm. Each passes the <0.74315 cm mean gate; R8 passes independently
before R9 becomes eligible. Selection among R7/R8/R9 uses all ten scans,
in-sample; only rounds 1–2 cross-fit parameters. The selected R9 also passes
the packed comparison with v3, without retuning. Sources:
`outputs/mesh_extents/rules-round3/summary.md` and
`outputs/mesh_extents/round3-job-b/job-b.md`.

Over three kit sampling seeds, mean per-object sampling SD is 0.0069 cm for v3
and 0.0053 cm for v4, maximum 0.0214 cm: sampling variability, not uncertainty
on new objects.

On eight public training episodes, pose MPPE is 22.82 cm for the earlier rule, 20.84 cm for stereo shrinkage and
20.80 cm for uniform shrinkage. Both pose success rates are zero.
The PDF has two main pages and one references page, with no overfull boxes;
the pinned engine emits the known microtype tracking error.

## Caveats

- Public scans supplied development scores and visual context; mesh constructors
  use only video-derived extents and attributes. Prior scan exposure informed
  rule design, attribute reading and episode-39 thresholds. A third adaptive
  round raises selection optimism by an unknown amount. Round 3 rebuilt objects
  among the worst-scoring on the scans; the thin-tool rule is a second attempt
  on the same two scanned tools after round 1's failure. The rack compartment
  was visible in scan renders seen earlier. The rack/tool rules affect one/two
  scanned objects, close to our own stricter per-object shape-choice ban;
  that ban is not a challenge rule. These are development estimates.
- The spoon (ten of 36 leaderboard pairs) changes from a box to a bowl and
  handle without any scan, using medium-confidence depth ratios. CD-O between
  its new mesh and old box is 1.32–1.39 cm. An average spoon regression of
  about 0.39 cm would cancel the measured gain over all 36 pairs:
  `26 * (0.8115 - 0.6629) / 10 = 0.38636 cm`. Its leaderboard effect is
  unknown; spoon pairs are excluded from reported means. This shape-change
  distance does not measure reconstruction accuracy.
- Manual identities, predicted depth and distorted proportions limit meshes.
  Remaining CD-O is 1.487 cm for the pitcher (spout missing), 0.858 for the
  pot and 0.865 for the rack. Closed components retain internal faces.
- Stereo shrinkage was selected after results under a changed rejection rule.
  One-object tuning episodes cannot establish a second-object correction.
  The 0.04 cm gap from uniform shrinkage establishes neither calibration
  benefit nor equivalence.
- Static rollouts, unknown camera-to-mocap heading, assumed evaluation
  calibration and approximate scan sampling limit pose interpretation.
  Initial-placement errors measure neither tracking nor success; no official
  pose-score gain is established.
