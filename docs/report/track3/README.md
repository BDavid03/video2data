# Track 3 extended abstract

A two-page anonymous abstract describes video-measured primitive meshes and
static-object poses. Shells and rack pegs improve mesh scores on reused public
scans; the pose results establish neither calibration benefit nor manipulation
success. References occupy a separate third page.

## Build

From the checkout root:

```bash
bash scripts/reproduce/d3_report.sh --run
```

This builds committed HEAD with the pinned Tectonic engine, regenerates the
figures, and prints the temporary build directory containing the PDF and logs.
To build uncommitted edits, copy `docs/report/track3` and run the same figure
and compilation commands shown in the script against that copy.

## Latest result

Packaged CD-O on 26 scanned pairs covering ten objects, in cm (lower is better):

| Mesh | Object mean | Pair mean |
| --- | ---: | ---: |
| Boxes | 1.0091 | 1.2547 |
| Cylinder-plus-handle (v2) | 0.9257 | 1.0850 |
| Shells and peg rack (v3) | **0.7711** | **0.8115** |

The v3 comparison improves 19 pairs and leaves seven unchanged. Cross-fitted
selection gives 0.773 cm per object. On eight public training episodes, pose
MPPE is 22.82 cm for the earlier rule, 20.84 cm for stereo shrinkage and
20.80 cm for uniform shrinkage. Both pose success rates are zero.
The PDF has two main pages and one references page, with no overfull boxes;
the pinned engine emits the known microtype tracking error.

## Caveats

- Public scans informed development scoring, and rule design and attribute
  reading followed exposure to scan renders. Cross-fitting parameters cannot
  remove that exposure; these are development estimates. No scan geometry or
  dimension enters a submitted mesh. The per-object shape-choice ban is our
  stricter selection protocol, not a challenge rule.
- Manual identities, MoGe-2 predicted depth and distorted proportions limit
  reconstruction. The spoon is unscanned; ten of 36 pairs are excluded.
  Rack compartments and the pitcher spout remain unmodelled.
- Stereo shrinkage was selected after results under a changed rejection rule.
  One-object tuning episodes cannot establish a second-object correction.
  The 0.04 cm gap from uniform shrinkage establishes neither calibration
  benefit nor equivalence.
- Static rollouts, unknown camera-to-mocap heading, assumed evaluation
  calibration and approximate scan sampling limit pose interpretation.
  Initial-placement errors measure neither tracking nor success; no official
  pose-score gain is established.
