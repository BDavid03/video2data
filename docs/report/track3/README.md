# Track 3 extended abstract

A two-page anonymous abstract describes video-measured primitive meshes and
static-object poses. V4 adds a compartment rack and thin-tool profiles to vessel
shells, improving mesh scores on reused public
scans; the pose results establish neither calibration benefit nor manipulation
success. References occupy a separate third page.

## Build

From the checkout root:

```bash
bash scripts/reproduce/d3_report.sh --run
```

This builds committed HEAD with the pinned Tectonic engine, regenerates the
figures, and prints the temporary build directory containing the PDF and logs.
To build uncommitted edits, copy `docs/report/track3` and run the same figure
and compilation commands shown in the script against that copy.

## Latest result

Packaged CD-O on 26 scanned pairs covering ten objects, in cm (lower is better):

| Mesh | Object mean | Pair mean |
| --- | ---: | ---: |
| Boxes | 1.0091 | 1.2547 |
| Cylinder-plus-handle (v2) | 0.9257 | 1.0850 |
| Shells and peg rack (v3) | 0.7711 | 0.8115 |
| Rack and tools (v4) | **0.6534** | **0.6629** |

V4 versus v3 improves nine pairs, leaves 17 unchanged and worsens none.
Object means fall from 1.368 to 0.865 cm for the rack, 1.054 to 0.518 for the
pan, and 0.719 to 0.582 for the sweeper. The packaged file is in
`submissions/20261102T0516Z-d1-v4/`.

Round-3 rules have frozen video attributes and no free parameters: R7 adds the
rack compartment, rim and lower pegs; R8 gives all thin tools measured heads
and grips; R9 combines both. Their three-seed development means are
0.72009, 0.70576 and 0.65270 cm, with zero regression against R6/0.10's
0.77315 cm. Each passes the <0.74315 cm mean gate; R8 passes independently
before R9 becomes eligible. For these parameter-free rules, cross-fitted
scores equal all-ten-object scores. The selected R9 also passes the packed
comparison with v3, without retuning. Sources:
`outputs/mesh_extents/rules-round3/summary.md` and
`outputs/mesh_extents/round3-job-b/job-b.md`.

On eight public training episodes, pose
MPPE is 22.82 cm for the earlier rule, 20.84 cm for stereo shrinkage and
20.80 cm for uniform shrinkage. Both pose success rates are zero.
The PDF has two main pages and one references page, with no overfull boxes;
the pinned engine emits the known microtype tracking error.

## Caveats

- Public scans informed development scoring, and rule design and attribute
  reading followed exposure to scan renders. Cross-fitting parameters cannot
  remove that exposure. A third adaptive round on the same ten scans raises
  selection optimism by an unknown amount; these are development estimates.
  No scan geometry or dimension enters a submitted mesh. The rack rule changes
  one scanned object, the tool rule two. The per-object shape-choice ban is our
  stricter selection protocol, not a challenge rule.
- Manual identities, MoGe-2 predicted depth and distorted proportions limit
  reconstruction. The unscanned spoon changes from a box to the shared R8
  shallow-bowl/handle profile; its effect on ten of 36 leaderboard pairs is
  unknown, and those pairs are excluded from reported means. Remaining CD-O
  is 1.487 cm for the pitcher (spout missing), 0.858 for the pot and 0.865 for
  the rack. Video ratios are approximate; closed components retain internal faces.
- Stereo shrinkage was selected after results under a changed rejection rule.
  One-object tuning episodes cannot establish a second-object correction.
  The 0.04 cm gap from uniform shrinkage establishes neither calibration
  benefit nor equivalence.
- Static rollouts, unknown camera-to-mocap heading, assumed evaluation
  calibration and approximate scan sampling limit pose interpretation.
  Initial-placement errors measure neither tracking nor success; no official
  pose-score gain is established.
