# Rebuilding the non-technical report

`report.md` and its figures are generated by `scripts/report/nontechnical_figures.py`.
From the checkout root:

```bash
CUDA_VISIBLE_DEVICES='' JAX_PLATFORMS=cpu OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 NUMEXPR_NUM_THREADS=1 PYTHONPATH=. nice -n 19 data/.runtime/linux-cuda/bin/python -B scripts/report/nontechnical_figures.py
```

This rebuilds the report, figures, table and videos from saved outputs on CPU. It reads
cached camera JPEGs and masks for episodes 39 and 38, and no scans or challenge labels.
It never scores or packs. Videos must stay below 5 MB. No test suite runs.

Options: `--replay` reruns all four CPU policy diagnostics first, `--replay-pan` runs M2,
`--replay-video-policy` runs M2v on 39, and `--replay-video-policy 38` runs only 38. Replay
uses the isolated FlashCHORD interpreter; the M0c log is
`data/outputs/visuals/policy-hands/m0c/replay.log`, with `status.json` and `summary.json`
beside it. For example:

```bash
CUDA_VISIBLE_DEVICES='' JAX_PLATFORMS=cpu OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 nice -n 19 data/.runtime/linux-cuda/bin/python -B scripts/report/nontechnical_figures.py --replay-video-policy
CUDA_VISIBLE_DEVICES='' JAX_PLATFORMS=cpu OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 NUMEXPR_NUM_THREADS=1 PYTHONPATH=. nice -n 19 data/.runtime/linux-cuda/bin/python -B scripts/report/nontechnical_figures.py --replay-video-policy 38
```

To replay a finished policy directly:

```bash
CUDA_VISIBLE_DEVICES='' JAX_PLATFORMS=cpu data/.runtime/flashchord/venv/bin/python -u -B scripts/report/policy_hands.py \
  --checkpoint data/outputs/moving_policy/ep39-a1/training/policy_66763776.safetensors \
  --task data/outputs/moving_policy/ep39-a1/motion/sequence_id=episode_000039/robot_name=sharpa_wave/task.parquet \
  --output data/outputs/visuals/policy-hands/ep39 \
  --official data/outputs/moving_policy/ep39-a1/score-66763776/trajectory.parquet
```

For another checkpoint, pass its task, an output directory and its matching export, or
`--no-official`. Checkpoint identity must match the export metadata, and only FlashSAC is
supported. The script changes only these things: one world, CPU, deterministic inference,
frame-zero reset, and the upstream evaluation setup that removes assistance. The report
shows the fixed M0c, M2, M2v and episode 38 results; add another replay to the builder by hand.

Replay output: per-step body poses (xyzw), goal poses and timing; `geometry.npz` with the
drawing geometry; `contacts.json` with contact partners, positions and solver forces.
Forces are raw simulator estimates. Contact counts do not show force closure, grip strength
or a natural grasp.

`EP38_IN_ENTRY` and `POSE_SCORES`, near the top of the generator, control the entry-status
and pose-score text. Provenance is in `data/outputs/visuals/inputs.json` (hashed inputs per
figure) and `build-summary.json` (numeric checks, decoded video frames, paths).

## What the figures can and cannot show

Policy pictures are orthographic drawings with a fixed camera, using recorded link
transforms and the scene's visual meshes simplified by 1.5 mm vertex clustering. Blue
dashed lines are the goal's mesh-oriented bounding box. An earlier version used
body-axis-aligned bounds, which made the goal look rotated and too large; the audit is in
`data/outputs/visuals/goal-box-angle-audit.json`. Across 390 steps the achieved-to-goal angle
is 0.515 degrees mean and 1.932 maximum in CPU replay, and 0.539 and 1.977 in the official export.

The report also records these points:

- The first tracker failed. Candidate C failed the first frozen checks and the amendment,
  and work continued under a conditional rule written before the sealed label comparison.
  This is weaker evidence, and the report says so.
- The table checks do not establish label-based accuracy or adoption on 38, whose
  world-path accuracy is unknown.
- Episode 38 was stopped and resumed twice and lost its replay each time. Its midpoint
  failure is undiagnosed.
- CD-O 0.53562 cm, all five pose-board rejections and the replaced kit are stated. Every pose
  number shown uses the old scorer.
